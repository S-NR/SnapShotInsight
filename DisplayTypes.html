🖥️ Embedded Systems Display Types

Character LCD (e.g. 16×2, 20×4)

Interface: Parallel or I²C (HD44780‑type)

Use Cases: Simple text display, meters, clocks

  • Low cost; easy to drive
  • No graphics support

OLED / Graphic OLED

Interface: SPI or I²C

Use Cases: Wearables, small UIs, IoT device indicators

  • High contrast; no backlight needed
  • Small size modules (0.96″–1.5″)

TFT / IPS LCD

Interface: SPI / RGB / MIPI

Use Cases: Industrial HMIs, portable GUIs

  • Full‑color, high refresh
  • Often paired with touch panels

E‑Ink / E‑Paper

Interface: SPI

Use Cases: e‑readers, low‑power IoT dashboards

  • Ultra‑low power (image holds without energy)
  • Excellent sunlight readability
  • Slow refresh rate

VFD (Vacuum Fluorescent Display)

Interface: Parallel / custom driver

Use Cases: Legacy audio panels, meters, POS displays

  • Bright & distinct, wide temp range
  • Self‑emissive glowing segments

Nextion HMI Display

Interface: UART serial

Use Cases: Industrial touch UIs, appliances

  • On‑board MCU + GUI builder
  • Offloads graphics from main MCU

LED Matrix (8×8 up to 32×8…)

Interface: MAX7219/SPI or WS2812 RGB

Use Cases: Scrolling text, icons, visual notifications

  • Chainable modules; dynamic display
  • Mono or full‑color+animation

Flexible OLED

Interface: SPI or RGB driver

Use Cases: Wearables, curved/foldable displays

  • Bendable modules (e.g. 160×32 pixels)
  • Durable plastic substrate

Transparent Displays

Type: Transparent OLED / specialty screens

Use Cases: AR windows, futuristic UIs

  • See‑through display glass
  • Used in high‑end concepts

Bar Graph Displays

Type: LED or LCD bar segments

Use Cases: Volume meters, signal strength indicators

  • Analog-style level representation
  • Easy to read at a glance

7‑Segment / 14‑Segment Displays

Type: LED or LCD segmented digits/letters

Use Cases: Clocks, elevator panels, simple readouts

  • Numeric (7‑segment) or alphanumeric (14/16‑segment)
  • Low power, easy to drive

Laser / Projection Displays

Type: Scanning laser projector or LCoS

Use Cases: HUDs, medical, near‑eye systems

  • Projects image onto surfaces
  • Very niche, specialized use
