Encoding Alignment & Verification Process

1️⃣ VS Code Project Structure

This is how your project folder typically looks:

ProjectRoot/
│
├── .vscode/
│   └── settings.json
│
├── src/
│   ├── main.c
│   ├── app.c
│   └── app.h
│
├── include/
│   └── config.h
│
└── README.md

Encoding settings can be defined:

  • Globally (User Settings)
  • Per Project inside .vscode/settings.json

2️⃣ Check IDE Encoding

  • Open MPLAB / STM
  • Check default charset
  • Confirm if it is UTF-8 or ISO-8859-1

3️⃣ Update VS Code To Match

Open Command Palette:

Ctrl + Shift + P

Type:

Preferences: Open Settings (JSON)

Add or update:

"files.encoding": "utf8",
"files.autoGuessEncoding": false

If your IDE uses ISO-8859-1 instead: 

"files.encoding": "iso88591"

4️⃣ Restart & Verify

  • Close the project in VS Code completely
  • Close VS Code completely
  • Reopen project
  • Open a .c or .h file
  • Check bottom-right encoding indicator

5️⃣ Test & Confirm

Add a test comment:

// Test: ü é ñ © µ
  • Save the file
  • Open the same file in IDE
  • Verify no junk characters appear

If no corrupted characters appear → Encoding alignment is correct.

6️⃣ Adding Encoding at Project Level (.vscode)

Create or open:

ProjectRoot/.vscode/settings.json

Add:

{
  "files.encoding": "utf8",
  "files.autoGuessEncoding": false
}

This ensures everyone opening the project uses the same encoding.

7️⃣ Final Safety Checklist

  • IDE encoding checked ✔
  • VS Code encoding updated ✔
  • VS Code restarted ✔
  • Bottom-right encoding verified ✔
  • Test special characters validated ✔
