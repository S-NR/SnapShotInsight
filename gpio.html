🧠 GPIO – General Purpose Input/Output

What is GPIO?

GPIO stands for General Purpose Input/Output. It refers to the digital pins on a microcontroller that can be programmed to either receive signals (input) or send signals (output).

🪜 GPIO: From Zero to Expert

🟢 Level 0: Beginner

Think of a microcontroller like a mini computer. The "pins" are its physical connectors. GPIO pins let it interact with the outside world.

  • Button → GPIO input → Detect press
  • LED ← GPIO output ← Turn LED ON/OFF
🟡 Level 1: Basic Understanding

Input Mode: Microcontroller listens to a signal.
Output Mode: Sends a digital signal (HIGH/LOW).

Digital Logic:

  • HIGH = 1 (usually 3.3V or 5V)
  • LOW = 0 (0V)
pinMode(PIN_X, INPUT);
pinMode(PIN_Y, OUTPUT);
🟠 Level 2: Practical Knowledge

Input Configurations: Floating, Pull-Up, Pull-Down
Output Types: Push-Pull, Open-Drain

Interrupts: GPIO can trigger ISR on edge detection.

🟣 Level 4: Advanced – Register-Level Example (STM32)
// Enable clock
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;

// Set PA5 as output
GPIOA->MODER &= ~(3 << (5 * 2));
GPIOA->MODER |=  (1 << (5 * 2));

// Set PA5 HIGH
GPIOA->ODR |=  (1 << 5);

// Set PA5 LOW
GPIOA->ODR &= ~(1 << 5);
🔴 Level 5: Expert Concepts
  • Debouncing: Filter noisy input from mechanical buttons.
  • Interrupt Priorities: Handle events in real-time systems.
  • Drive Strength: Adjust how strong the pin drives signals.
  • EMI Management: Reduce electromagnetic noise in fast toggles.
  • Low Power: Disable unused GPIOs to save power.
