Why This Happens

This occurs when different tools use different encodings:

  • File saved as UTF-8
  • Opened as Windows-1252 / ANSI
  • Generated by STM32 / MPLAB / Keil in ISO format
  • Modified by Git or external editors
  • AI tools auto-insert Unicode symbols

The characters are correct — they are simply decoded incorrectly.

Permanent Fix in VS Code

1️⃣ Set Default Encoding 
Ctrl + Shift + P
→ Preferences: Open Settings (UI)
→ Search: encoding

Set:
Files: Encoding = utf8
Files: Auto Guess Encoding = Enabled
2️⃣ Fix Already Corrupted File 
Bottom Right Corner → Click Encoding
→ Reopen with Encoding
→ Select UTF-8
3️⃣ Save Properly 
Save with Encoding → UTF-8

⚠ If Using GitHub Copilot or AI Tools

  • Copilot may replace degC with °C
  • May auto-insert ², ³, µ symbols
  • If file is not UTF-8 → corruption returns

Best Practice for Embedded / Firmware Projects

For STM32 / MPLAB / microcontroller code, avoid direct special characters. They can:

  • Break compilers
  • Increase flash usage
  • Corrupt display fonts
  • Cause Git diff noise
Instead of: 
m²
m³
µA
°C
Use: 
m^2
m^3
uA
degC

Safe Format for JSON / Language Files

{
   "square_unit": "m\u00B2",
   "cubic_unit": "m\u00B3",
   "degree": "\u00B0C"
}

Git Protection

git config --global i18n.commitEncoding utf-8
git config --global i18n.logOutputEncoding utf-8

Optional .gitattributes:

*.c text working-tree-encoding=UTF-8
*.h text working-tree-encoding=UTF-8
*.json text working-tree-encoding=UTF-8

Recommended Workspace Setting

.vscode/settings.json

{
  "files.encoding": "utf8",
  "files.autoGuessEncoding": true,
  "files.eol": "\n"
}
