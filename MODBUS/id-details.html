Why Modbus Uses ID Range 1–247

Address 0 is used for broadcast (no reply).

Why this range?

Addresses 248–255 are reserved for diagnostics or future features.

Valid device ID range:

1 to 247 — guaranteed compatible for all Modbus RTU/ASCII networks.

Reasons:

  • Reserved addresses for special operations
  • Original Modbus RTU spec restricts devices to 1–247
  • Ensures interoperability across PLCs, meters, HMIs
  • Many masters reject IDs >247
