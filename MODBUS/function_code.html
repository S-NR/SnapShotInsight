Important Modbus Function Codes

This document explains the most commonly used Modbus function codes — what they are, what they do, why they exist, and how they are used in real industrial systems.

What Are Modbus Function Codes?

In Modbus communication, every request sent by a Master (Client) to a Slave (Server) contains a Function Code.

A function code is an instruction that tells the slave what operation to perform on its internal data.

Without function codes, Modbus frames would be just raw bytes with no meaning. Function codes define the purpose of the message.

Why Function Codes Are Needed

  • Different types of data exist inside a device
  • Some data is read-only, some is writable
  • Some data is 1-bit, some is 16-bit
  • Safety and reliability require strict access control
Function codes ensure that the correct type of operation is performed on the correct type of data.

Function Code 01 — Read Coils

Purpose: Reads the ON/OFF status of digital outputs.

What it does

Returns the current state of one or more coils as individual bits.

Why it is used

Allows monitoring of output states without changing them.

Real-world examples

  • Is a motor running?
  • Is a valve open?
  • Is a relay energized?

Function Code 02 — Read Discrete Inputs

Purpose: Reads digital input signals.

What it does

Retrieves the state of read-only digital inputs.

Why it is used

Prevents accidental modification of hardware input signals.

Real-world examples

  • Push button status
  • Limit switch state
  • Proximity sensor output

Function Code 03 — Read Holding Registers

Purpose: Reads read/write registers.

What it does

Returns values stored in holding registers.

Why it is used

Holding registers store configuration data and calculated values.

Real-world examples

  • Flow totalizer values
  • Speed or pressure setpoints
  • Alarm thresholds

Function Code 04 — Read Input Registers

Purpose: Reads measurement data.

What it does

Returns read-only 16-bit measurement values.

Why it is used

Keeps sensor values protected from modification.

Real-world examples

  • Temperature
  • Pressure
  • Voltage and current

Function Code 05 — Write Single Coil

Purpose: Controls one digital output.

What it does

Sets a single coil ON or OFF.

Why it is used

Simple and reliable control of individual outputs.

Real-world examples

  • Start or stop a motor
  • Open or close a valve

Function Code 06 — Write Single Register

Purpose: Writes one configuration value.

What it does

Updates a single holding register.

Why it is used

Safe modification of individual parameters.

Real-world examples

  • Change speed setpoint
  • Update operating mode

Function Code 15 (0F) — Write Multiple Coils

Purpose: Controls multiple outputs in one command.

Why it is used

Reduces communication overhead and allows synchronized updates.

Real-world examples

  • Control multiple relays
  • Reset alarms

Function Code 16 (10) — Write Multiple Registers

Purpose: Writes blocks of configuration data.

Why it is used

Efficient transfer of structured or multi-register data.

Real-world examples

  • Recipe download
  • Bulk configuration
  • 32-bit and 64-bit values
