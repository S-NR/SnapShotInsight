MODBUS Function Code 01 — Read Coils

← Back

1. What is a Coil?

In MODBUS, a coil represents a single digital output bit. It is typically mapped to physical outputs such as relays, solenoids, motors, or valves.

  • Size: 1 bit
  • 0 → OFF
  • 1 → ON

Although coils are writable, they are also readable so that the master can verify the actual output state.

2. Purpose of Function Code 01

Function Code 01 is used to read the ON/OFF status of one or more coils. It does not change any output state.

3. Why Read Coils is Used

  • Verify that a write command was executed
  • Monitor output status in real time
  • Fault detection (stuck ON / OFF)
  • HMI display and diagnostics

MODBUS strictly separates control and monitoring for safety and predictability.

Coil Addressing

Coils are often documented using the 0xxxx notation. 


Coil 00001 → Address 0x0000
Coil 00008 → Address 0x0007

Note: MODBUS protocol uses zero-based addressing. The 0xxxx format is only for documentation.

4. How It Works (High-Level)

Master → Sends Read Coils request
Slave → Validates request & CRC
Slave → Reads internal coil memory
Slave → Packs bits into response
Master → Decodes ON/OFF states

5. MODBUS RTU Request Frame

Slave ID      : 0x01
Function Code : 0x01 (Read Coils)
Start Address : 0x0000
Quantity      : 0x0008 (8 coils)
CRC           : Calculated

This request asks the slave to return the status of 8 coils starting from address 0.

6. MODBUS RTU Response Frame

Slave ID      : 0x01
Function Code : 0x01
Byte Count    : 0x01
Coil Data     : 0b01011001
CRC           : Calculated

Each bit represents one coil. The least significant bit (LSB) corresponds to the first requested coil.

7. Coil Bit Packing

Bit position: 7 6 5 4 3 2 1 0
Coil state :  0 0 1 0 1 1 0 1
Hex value  :  0x2D

MODBUS packs multiple coils into bytes to minimize bandwidth usage.

The least significant bit (LSB) corresponds to the first requested coil.

8. Master-Side Pseudocode

build_read_coils_request(slave, start, quantity)
send_request()

response = receive_response()
if crc_invalid(response):
    error

    state = (data_byte >> bit_index) & 1

9. Slave-Side Pseudocode

if function_code == READ_COILS:
    validate_address()
    read_coil_states()
    pack_bits()
    send_response()

10. Real-World Examples

  • Motor running? → Read motor control coil
  • Valve open? → Read solenoid output
  • Relay energized? → Confirm control logic

Common Implementation Mistakes

  • Using FC01 to read discrete inputs (should use FC02)
  • Wrong coil offset (00001 vs 0x0000)
  • Incorrect bit order interpretation
  • Ignoring maximum coil limits

Key Design Rule

FC01 reads output coils only.
For input-only digital signals, always use Function Code 02.

11. Key Takeaways

  • Reads digital output states
  • Non-destructive operation
  • Bit-packed response
  • Essential for monitoring & diagnostics
