CRC Calculation in Modbus RTU

1. What is CRC in Modbus RTU?

CRC (Cyclic Redundancy Check) is an error-detection mechanism used in Modbus RTU communication.

Each Modbus RTU frame ends with a 16-bit CRC that allows the receiver to detect transmission errors.

A typical Modbus RTU frame:

[ Slave ID ] [ Function Code ] [ Data ... ] [ CRC Low ] [ CRC High ]

The CRC is calculated over all bytes except the CRC itself.

2. CRC Basics (Modbus RTU Specific)

ParameterValue
CRC Width16 bits
Initial Value0xFFFF
Polynomial0xA001
Bit OrderLSB first
Shift DirectionRight Shift
Final XORNone

Important: Modbus uses a reflected polynomial. That is why 0xA001 is used instead of 0x8005.

3. CRC Calculation – Step by Step

Example Data

01 03 00 10 00 02

Step 1: Initialize CRC

CRC = 0xFFFF

Step 2: Process Each Byte

For each byte in the message:

  1. XOR the byte with the low byte of CRC
  2. Process 8 bits:
Repeat 8 times:
    If (CRC & 0x0001) == 1
        CRC = (CRC >> 1) ^ 0xA001
    Else
        CRC = CRC >> 1

4. Final CRC Result

Final CRC Register: 0xCEC5

Transmission Order (Modbus RTU):

CRC Low Byte  = C5
CRC High Byte = CE

5. Key Points to Remember

  • CRC is calculated LSB-first
  • Polynomial used is 0xA001
  • Right shift is mandatory
  • CRC bytes are transmitted low byte first
  • No final inversion is applied

6. Reference Pseudocode

uint16_t modbus_crc(uint8_t *data, uint16_t length)
{
    uint16_t crc = 0xFFFF;

    for (uint16_t i = 0; i < length; i++)
    {
        crc ^= data[i];
        for (uint8_t j = 0; j < 8; j++)
        {
            if (crc & 0x0001)
                crc = (crc >> 1) ^ 0xA001;
            else
                crc >>= 1;
        }
    }
    return crc;
}
