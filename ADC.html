Analog to Digital Converter (ADC) Overview

1. Hardware Level (Analog Domain)

  • Analog Input: Voltage or current signals (e.g., sensors).
  • Sample & Hold: Captures the analog value at an instant.
  • ADC Core: Converts analog voltage to binary digital value.
  • Resolution: Defines precision (8-bit, 10-bit, 12-bit, etc.).
  • Reference Voltage: Sets conversion scale (e.g., 0–3.3V).

2. Firmware Level (Digital Domain)

  • Initialization: Configure ADC registers (channel, sampling rate, resolution).
  • Start Conversion: Trigger ADC (polling, interrupt, DMA).
  • Read Data: Fetch digital values from ADC data register.
  • Scaling: Convert raw ADC values to engineering units (°C, voltage, etc.).

3. Debugging ADC

  • Check reference voltage stability.
  • Verify GPIO pin configuration as analog input.
  • Ensure sampling time matches sensor characteristics.
  • Test by applying known voltage and verifying digital value.

4. Typical ADC Workflow

Sensor (Analog Signal) → Sample & Hold → ADC Conversion → Digital Value → Processing in MCU → Application Output

5. Example Code (STM32 HAL)


ADC_HandleTypeDef hadc1;

HAL_ADC_Start(&hadc1);
if (HAL_ADC_PollForConversion(&hadc1, 100) == HAL_OK)
{
    uint32_t adcValue = HAL_ADC_GetValue(&hadc1);
    float voltage = (adcValue * 3.3) / 4095; // For 12-bit ADC
}
HAL_ADC_Stop(&hadc1);
Note: Debugging ADC often requires an oscilloscope or multimeter to validate input signals.
