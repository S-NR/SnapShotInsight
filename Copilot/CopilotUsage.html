1. What Changed?

Premium Request Units (PRUs)AI Credits (AICs)
Flat allowance modelUsage based on model and token consumption
Minimal model cost differencesModel selection significantly impacts cost

1 AI Credit (AIC) = $0.01 USD.

2. Understanding Tokens

Models are billed per million tokens. A token is approximately a word fragment, code fragment, or symbol.

TypeDescription
InputNew prompt content sent to the model
Cached InputPreviously processed content reused at lower cost
Cache WriteCreating cache entries for future reuse
OutputModel generated response
Prompt 1:
20,000 tokens -> Full Input Rate

Prompt 2:
20,000 cached tokens -> Cached Rate
10,000 new tokens -> Full Input Rate

4. Copilot Interaction Modes

Different Copilot modes perform different levels of analysis and may consume different amounts of AI Credits depending on the files, tools and context involved.

Mode Comparison

Mode Project Scope Typical Cost
