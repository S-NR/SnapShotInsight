📏 Calibration Overview

🔧 What is Calibration?

Calibration is the process of adjusting and verifying a device or sensor to ensure its output matches a known standard. This is crucial for accurate measurements and consistent system behavior.

🎯 Why is Calibration Needed?

  • ✅ Ensure accuracy of sensor readings
  • ✅ Maintain consistency across measurements
  • ✅ Meet industry standards and regulations
  • ✅ Compensate for offsets, gain errors, or drift

📐 Types of Calibration (with Formulas)

Calibration Type Description Formula
Single-Point Calibration Corrects only offset error Corrected = Raw - Offset
Two-Point Calibration Corrects both offset and gain (linear) Corrected = (Raw × Gain) + Offset
Multi-Point Calibration Used for slightly nonlinear devices Uses interpolation between known values
Polynomial Calibration Fits a curve for highly nonlinear devices Corrected = a0 + a1×Raw + a2×Raw² + ...
Zero & Span Calibration Industrial term for 2-point calibration Same as 2-point formula

📊 Two-Point Calibration – In Detail

This is the most common method used when sensors behave linearly.

  1. Take two reference points: (Raw1, Actual1) and (Raw2, Actual2)
  2. Calculate Gain:
    Gain = (Actual2 - Actual1) / (Raw2 - Raw1)
  3. Calculate Offset:
    Offset = Actual1 - (Gain × Raw1)
  4. Final formula:
    Calibrated = (Raw × Gain) + Offset

🧮 Example

Given:

  • Raw1 = 100, Actual1 = 0
  • Raw2 = 900, Actual2 = 100
  • Raw input = 500

Gain = (100 - 0) / (900 - 100) = 0.125
Offset = 0 - (0.125 × 100) = -12.5
Result: Calibrated = (500 × 0.125) - 12.5 = 50
