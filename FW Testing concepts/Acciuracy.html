Accuracy (Easy Explanation)

Accuracy means how close the value reported by the firmware is to the actual (true) value.

👉 If the actual value is 100 and the firmware shows 99.8, the system is accurate.
👉 If it shows 95, it is not accurate, even if it always shows 95.

How a Real Device Measures a Value

A firmware never measures a physical value directly. It goes through multiple stages before producing the final output. 

                 Physical Quantity
              (Temp / Pressure / Flow)
                         |
                         v
                      Sensor
              (Physical → Electrical)
                         |
                         v
               Signal Conditioning
                (Amplify / Filter)
                         |
                         v
                        ADC
                (Analog → Digital)
                         |
                         v
                     Firmware
              (Scaling, calibration,
               compensation)
                         |
                         v
                   Output Value
              (Display / MODBUS / UART)

✅ Accuracy is checked at the final output, not just at the sensor or ADC.

Numeric Example (Very Important)

Reference (Golden Standard)
A calibrated lab instrument shows: 100.00 units

Firmware Output
The device reports: 98.50 units 

Accuracy Error Calculation

Error = Measured − Actual
Error = 98.50 − 100.00
Error = −1.50 units


Accuracy Error (%)

Accuracy Error (%) =
(|Error| / Actual) × 100
= (1.5 / 100) × 100
= 1.5%

✅ If the specification allows ±2% accuracy → PASS
❌ If the specification allows ±1% accuracy → FAIL

Accuracy vs Precision (Very Common Confusion)

Many beginners confuse accuracy with precision. They are not the same. 

🎯 True Value (Target)
        |
        |
        X = 100   ← Actual correct value


Case 1: Precise but NOT Accurate

Readings:
  95
  95
  95
  95

(All readings are close together,
but far away from the true value)



Case 2: Neither Accurate nor Precise

Readings:
  92
  105
  88

(Readings are scattered
and also far from the true value)



Case 3: Accurate AND Precise

Readings:
  99.9
  100.1
  100.0

(Readings are close together
and close to the true value)

Precision = same result every time
Accuracy = correct result

Common Firmware Mistakes That Reduce Accuracy

  • Wrong calibration constants
  • Incorrect scaling formula
  • Using int instead of float
  • ADC reference voltage mismatch
  • Overflow or clipping
  • Missing temperature compensation
