Types of Endianness

  • Big-Endian: Stores the most significant byte (MSB) first (at the lowest memory address).
  • Little-Endian: Stores the least significant byte (LSB) first (at the lowest memory address).
  • Byte-Swapped: Bytes within each word are reversed.
  • Word & Byte Swapped: Both word order and byte order are reversed.

Why It Matters

Endianness becomes critical when data is transferred between systems, stored in files, or communicated over protocols like Modbus RTU. Different systems may expect different byte orders, leading to misinterpretation of values.

Examples with 0x12345678

The following table shows how the same 32-bit value is represented in different formats:

Format Memory Order (bytes) Reg1 (16-bit) Reg2 (16-bit) Combined Value
Big-Endian 12 34 56 78 1234 5678 12345678
Little-Endian 78 56 34 12 5678 1234 56781234
Big-Endian (Byte-Swapped) 34 12 78 56 3412 7856 34127856
Little-Endian (Word & Byte Swapped) 56 78 12 34 7856 3412 78563412
📌 In Modbus RTU communication, values larger than 16 bits are often split across multiple registers. Because of this, software/tools usually provide options to interpret data in Big-Endian, Little-Endian, or Swapped formats.
