Generate a PDF from Doxygen (Windows)

Doxygen → LaTeX → PDF using MiKTeX. Copy‑paste friendly commands included.

Prerequisites

  • Doxygen is installed and a Doxyfile exists in your project.
  • Enable LaTeX output in Doxyfile:
GENERATE_HTML  = YES
GENERATE_LATEX = YES
# Optional, recommended to keep output tidy
OUTPUT_DIRECTORY = docs

1) Install LaTeX (MiKTeX)

  1. Download and install MiKTeX.
  2. During setup, choose Install missing packages on the fly → Yes and Add MiKTeX to PATH.
You can use TeX Live instead, but it’s a much larger download.

2) Verify pdflatex is available

C:\> pdflatex --version

If you see version info (e.g., MiKTeX‑pdfTeX), you’re good. If not, add MiKTeX’s bin\x64 folder to your PATH via System Properties → Environment Variables, then open a new terminal and run where pdflatex.

3) Generate LaTeX with Doxygen

# From your project root (where Doxyfile lives)
> doxygen Doxyfile

# Expected folders (if OUTPUT_DIRECTORY=docs)
./docs/html/
./docs/latex/

4) Build the PDF

Go to the LaTeX output folder and use the generated build script:

> cd "D:\Projects\Head start training\a3_demo_project\Technical\Sources\Software\HS25_A3_Demo_Project\docs\latex"
> make.bat

Alternatively, build manually:

> pdflatex refman.tex
> makeindex refman.idx
> pdflatex refman.tex
> pdflatex refman.tex

Output: refman.pdf in the same latex folder.

Troubleshooting

  • 'pdflatex' is not recognized… → MiKTeX not installed or not in PATH. Add e.g. C:\\Program Files\\MiKTeX\\miktex\\bin\\x64 to PATH and reopen terminal.
  • Missing LaTeX packages → Allow MiKTeX to install on-demand when prompted, or pre‑install via MiKTeX Console.
  • Cross‑refs/TOC wrong → Run pdflatex multiple times (Doxygen’s make.bat does this).
  • Spaces in paths → Always wrap with quotes: "D:\\path with spaces\\...".
  • Clean build → Delete aux files then rebuild: 
    del /s /f *.ps *.dvi *.aux *.toc *.idx *.ind *.ilg *.log *.out *.brf *.blg *.bbl refman.pdf

Optional: Quick RTF → PDF (no LaTeX)

If you can’t install LaTeX, enable RTF output and print to PDF:

GENERATE_RTF = YES

Run Doxygen, open the generated .rtf in Word, then Save as → PDF.

Helpful Doxyfile snippet

# --- Project ---
PROJECT_NAME      = "HS25_A3_Demo_Project"
OUTPUT_DIRECTORY  = docs
OPTIMIZE_OUTPUT_FOR_C = YES

# --- Inputs ---
INPUT             = ./Sources ./Include
FILE_PATTERNS     = *.h *.c *.hpp *.cpp
EXTRACT_ALL       = YES
RECURSIVE         = YES

# --- Outputs ---
GENERATE_HTML     = YES
GENERATE_LATEX    = YES
HAVE_DOT          = YES
DOT_IMAGE_FORMAT  = svg
CALL_GRAPH        = YES
CALLER_GRAPH      = YES

Tip: Commit the generated docs/ to a separate branch (or publish only docs/html via GitHub Pages) and keep LaTeX artifacts out of main.
