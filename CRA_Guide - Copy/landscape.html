Quick lookup by system type

Industrial instrument (Modbus, USB, SD)

CRA default + EMC/LVD

Plus ATEX for Ex variants, MID if used for billing, Machinery Regulation if part of a machine. Customers under NIS2 ask for IEC 62443.

Device with radio

CRA + RED DA

RED Delegated Act (EN 18031) applies already; CRA takes over cybersecurity later.

Gateway / network module

CRA Important Class I

Routers, modems and network interfaces as core function need standards in full or a notified body.

Smart meter gateway

CRA Critical

Plus MID and national metering security rules.

Medical device

MDR / IVDR only

CRA excluded. A non-medical lab instrument is still in CRA scope.

AI feature in a machine

CRA + AI Act

If high-risk AI: CRA Annex I compliance helps meet AI Act cybersecurity.
