DWC2: system & attack surface

DWC2 is the controller firmware (SYSCTRL) for systec ultrasonic flow and heat measurement (deltawave family), in 1- and 2-channel variants and several language builds. This page shows what it is made of and where an attacker could get in.

Full analysis: · Source tree: DWC2 folder

Summary

MCUMicrochip PIC32MX575F512L: 512 KB flash, 64 KB RAM, no crypto accelerator; external MRAM for parameters
ToolchainsMPLAB 8 (, C32 v2.02) and MPLAB X (SYSCTRL.X, XC32 v5.00)
BootloaderBL 0.0.4 at 0x9D000000–0x9D00CFFF; app reset vector 0x9D00D000 (, ). Source not in repo
CRA scope / classIn scope Default → Module A
Other regimesEMC/LVD; MID MI-004 if heat is billed; ATEX for Ex variants; RED only with integrated radio
ReadinessLow Unsigned SD update, code protection off, master PIN, stack overflow in import
PositivesModbus writes compiled out; RS232 service commands compiled out; SonarQube in place

Key attack chain

1. AccessPhysical access to the SD card, or a PC connected over USB
→
2. PlantModified SYSCTRL.hex copied to the card
→
3. ResetBootloader checks only HEX checksums and address range, then programs flash
→
4. ImpactArbitrary firmware: falsified flow/heat/totalizer values to SCADA or billing

This is risk R01 (critical) and finding F1.
