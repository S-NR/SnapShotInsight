Firmware security baseline (practical checklist)

A reusable baseline that covers most of Part I for a typical MCU product:

Boot & update

Immutable bootloader, signed images, anti-rollback, fail-safe update, update procedure in user docs.

Debug & memory

Code protection on, JTAG/SWD disabled in production, bootloader write-protected, separate debug/release config.

Access

No universal password, unique or first-use credentials, attempt limiting, roles (viewer / operator / service).

Data integrity

CRC/MAC on configuration and calibration; corruption reported, not silently used.

Robust parsing

Bounded buffers on every file and frame parser; fuzz tests on host builds.

Evidence

Security event log, SBOM per release, CVE scan, static analysis report kept in the technical file.
