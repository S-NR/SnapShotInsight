EX-100: system & attack surface

EX-100 is the controller firmware (app) for ultrasonic flow and heat measurement (ultrasonic meter family), in 1- and 2-channel variants and several language builds. This page shows what it is made of and where an attacker could get in.

Summary

MCUMicrochip PIC32MX-class MCU: 512 KB flash, 64 KB RAM, no crypto accelerator; external MRAM for parameters
ToolchainsMPLAB 8 (legacy project file, C32 v2.02) and MPLAB X (MPLAB X project, XC32 v5.00)
Bootloaderthe legacy bootloader at 0x9D000000–0x9D00CFFF; app reset vector 0x9D00D000 (linker script, bootloader.hex). Source not in repo
CRA scope / classIn scope Default → Module A
Other regimesEMC/LVD; MID MI-004 if heat is billed; ATEX for Ex variants; RED only with integrated radio
ReadinessLow Unsigned SD update, code protection off, master PIN, stack overflow in import
PositivesModbus writes compiled out; RS232 service commands compiled out; SonarQube in place

Key attack chain

1. AccessPhysical access to the SD card, or a PC connected over USB
→
2. PlantModified app.hex copied to the card
→
3. ResetBootloader checks only HEX checksums and address range, then programs flash
→
4. ImpactArbitrary firmware: falsified flow/heat/totalizer values to SCADA or billing

This is risk R-01 (High, 12 on the 5×5 scale; top-ranked risk) and finding F1.
