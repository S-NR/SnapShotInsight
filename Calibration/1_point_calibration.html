1. One-Point Calibration

Uses a single known standard point to adjust the sensor's output. Assumes slope remains the same, only offset is corrected.

Formula:
Corrected Value = Measured Value + (Reference - Measured at Cal Point)
Example:
Measured value at reference 100°C = 98°C
Offset = 100 - 98 = 2°C
If sensor reads 150°C, corrected value = 150 + 2 = 152°C
