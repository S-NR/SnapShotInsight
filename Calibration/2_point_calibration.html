Formula:
Slope (m) = (Y₂ - Y₁) / (X₂ - X₁)
Offset (b) = Y₁ - m × X₁
Corrected Value = m × Measured + b
Example:
Point 1: Measured=98°C, Reference=100°C
Point 2: Measured=198°C, Reference=200°C
m = (200 - 100) / (198 - 98) = 100 / 100 = 1
b = 100 - (1 × 98) = 2
If measured = 150°C → Corrected = 1 × 150 + 2 = 152°C
