Advanced C Interview Questions & Answers (7–9 Yrs Experience)

1. Memory & Pointers

Q: Difference between const int *p, int * const p, and const int * const p?

const int *p → pointer to constant int (can change pointer, not the value).

int * const p → constant pointer to int (can change value, not the pointer).

const int * const p → constant pointer to constant int (neither can change).

Q: What happens if you dereference an unaligned pointer on ARM Cortex-M?

Many Cortex-M cores support unaligned access for 16-bit & 32-bit, but it’s slower. Some MCUs generate HardFault. Always align to natural word size for performance.

Q: Difference between stack, heap, static, global memory?

  • Stack → function-local, auto variables, fast, limited size.
  • Heap → dynamic allocation (malloc), fragmentation risk.
  • Static → persists for program lifetime, even if inside function.
  • Global → accessible anywhere, same lifetime as program.

Q: How would you implement your own malloc() in embedded systems?

#define HEAP_SIZE 1024
static char myheap[HEAP_SIZE];
static int offset = 0;


void* my_malloc(int size) {
if (offset + size > HEAP_SIZE) return NULL;
void* ptr = &myheap[offset];
offset += size;
return ptr;
}

Q: How do function pointers work? Example.

void hello(void) { printf("Hi\\n"); }
void (*fp)(void);
fp = hello;
fp(); // calls hello

Useful in callbacks, ISRs, driver APIs.

2. Bitwise Operations

Q: Count number of set bits.

int count_bits(unsigned int n) {
int count = 0;
while(n) { n &= (n-1); count++; }
return count;
}

Q: Extract leftmost set bit.

unsigned int leftmost(unsigned int n) {
n |= (n>>1);
n |= (n>>2);
n |= (n>>4);
n |= (n>>8);
n |= (n>>16);
return n - (n>>1);
}

Q: Check if number is power of 4.

int isPowerOf4(int n) {
return (n > 0) && !(n & (n-1)) && (n & 0x55555555);
}

Q: Reverse bits in a byte.

unsigned char reverse_bits(unsigned char b) {
b = (b & 0xF0)>>4 | (b & 0x0F)<<4;
b = (b & 0xCC)>>2 | (b & 0x33)<<2;
b = (b & 0xAA)>>1 | (b & 0x55)<<1;
return b;
}
