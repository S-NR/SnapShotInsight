Advanced C Interview Questions (7–9 Yrs Experience)

1. Explain memory layout of a C program.

A typical C program memory layout contains:

  • Text/Code Segment – stores instructions.
  • Data Segment – initialized global & static variables.
  • BSS Segment – uninitialized global & static variables.
  • Heap – dynamic memory allocation.
  • Stack – function call frames, local variables.

2. Difference between stack memory and heap memory?

  • Stack: Auto-managed, grows/shrinks with function calls, fast, limited size.
  • Heap: Dynamically allocated with malloc/calloc, manually freed, slower, larger but fragmentation possible.

3. How would you debug memory leaks in a large embedded C project?

Use tools like valgrind, mtrace, or implement custom memory allocation wrappers. Add counters/logs in malloc and free. Static analysis (Coverity, SonarQube) also helps.

4. Explain volatile and const together.

const volatile int *p;
- const: Code cannot modify the value.
- volatile: Value can change unexpectedly (e.g., hardware register).
Example: Read-only hardware status register.

5. How to prevent structure padding/alignment issues across compilers?

Use #pragma pack(1) or __attribute__((packed)). For cross-platform, use explicit serialization instead of direct struct dumps.

6. What are function pointers? Give a real use-case.

A function pointer stores the address of a function. Example: callback functions in drivers, or jump tables in protocol handlers. 

void (*fptr)(int);
fptr = &myFunction;
fptr(10);

7. What is the difference between deep copy and shallow copy?

  • Shallow copy: Copies only pointers, not the data they point to.
  • Deep copy: Allocates new memory and copies actual data.

8. Explain reentrant vs non-reentrant functions.

  • Reentrant: Can be safely interrupted and re-entered (no static/global state).
  • Non-reentrant: Uses static/global data, unsafe in multi-threaded or ISR contexts.

9. What happens if malloc fails?

malloc returns NULL. Always check before use.

10. What are race conditions? How do you prevent them in C?

Occurs when multiple threads access shared data concurrently without synchronization. Prevent using mutexes, semaphores, atomic operations, or disabling interrupts in embedded.
