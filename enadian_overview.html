Introduction to Endianness

1. What is Endianness?

Endianness refers to the byte order used to store multi-byte data (like 16-bit, 32-bit, or 64-bit values) in memory.

Big Endian (BE)

The most significant byte (MSB) is stored at the lowest memory address.
Think of it like how we normally write numbers (left to right).

Example: 0x12345678 stored as:

Address: 0x00 0x01 0x02 0x03
    Data: 12 34 56 78

Little Endian (LE)

The least significant byte (LSB) is stored at the lowest memory address. Reverse of Big Endian.

Example: 0x12345678 stored as:

Address: 0x00 0x01 0x02 0x03
    Data: 78 56 34 12

2. Swapped Logics

Terms like “byte-swapped” or “half-word swapped” appear in protocols and processors. These exist because different systems may use different endianness, requiring swaps during data transfer.

16-bit swap (word swap):
0x1234 (BE) → 0x3412 (LE)

32-bit swap (dword swap):
0x12345678 (BE) → 0x78563412 (LE)

64-bit swap (qword swap):
0x1122334455667788 (BE) → 0x8877665544332211 (LE)

Protocols like Modbus, CAN, Ethernet may use network byte order (Big Endian), but your MCU/PC may be Little Endian. Swaps are necessary when reading/writing across systems.

3. Converting Between Endianness

Two main approaches: manual shifting or built-in functions.

A. Manual Conversion (C example)

#include <stdint.h>


    // Swap 16-bit
    uint16_t swap16(uint16_t val) {
    return (val << 8) | (val >> 8);
    }


    // Swap 32-bit
    uint32_t swap32(uint32_t val) {
    return ((val >> 24) & 0x000000FF) |
    ((val >> 8) & 0x0000FF00) |
    ((val << 8) & 0x00FF0000) |
    ((val << 24) & 0xFF000000);
    }


    // Swap 64-bit
    uint64_t swap64(uint64_t val) {
    return ((val >> 56) & 0x00000000000000FFULL) |
    ((val >> 40) & 0x000000000000FF00ULL) |
    ((val >> 24) & 0x0000000000FF0000ULL) |
    ((val >> 8) & 0x00000000FF000000ULL) |
    ((val << 8) & 0x000000FF00000000ULL) |
    ((val << 24) & 0x0000FF0000000000ULL) |
    ((val << 40) & 0x00FF000000000000ULL) |
    ((val << 56) & 0xFF00000000000000ULL);
    }

B. Built-in Functions (GCC / Linux / Networking)

Most systems provide helpers:

  • htons() / htonl() → Host-to-Network (Big Endian)
  • ntohs() / ntohl() → Network-to-Host
  • GCC/Clang: __builtin_bswap16(x), __builtin_bswap32(x), __builtin_bswap64(x)

4. Where You’ll See Endianness Issues

  • Networking: TCP/IP always uses Big Endian (network byte order)
  • File formats: Some image/audio formats specify an endian type
  • MCUs: ARM Cortex-M → Little Endian, PowerPC → Big Endian
  • Protocols (like Modbus): sometimes swap word order inside registers
✅ Summary:
Big Endian → MSB first, Little Endian → LSB first.
Swapped formats occur when exchanging data across different systems.
Conversions are done using byte swaps (manual shifts or built-ins).
