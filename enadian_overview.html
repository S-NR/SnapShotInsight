Introduction to Endianness

Endianness defines the order in which bytes are stored or transmitted for multi-byte values in memory. It is important when transferring data between devices or working with binary file formats.

1. Big Endian

In Big Endian format, the most significant byte (MSB) is stored at the lowest memory address, and the least significant byte (LSB) at the highest address.

Example: 32-bit value 0x12345678 in memory:

Address 0x00: 12
Address 0x01: 34
Address 0x02: 56
Address 0x03: 78

2. Little Endian

In Little Endian format, the least significant byte (LSB) is stored at the lowest memory address, and the most significant byte (MSB) at the highest address.

Example: 32-bit value 0x12345678 in memory:

Address 0x00: 78
Address 0x01: 56
Address 0x02: 34
Address 0x03: 12

3. Why Endianness Matters

  • Networking protocols (e.g., TCP/IP) expect data in a specific byte order.
  • MODBUS RTU registers require high-byte first.
  • Reading binary files between systems with different endianness can cause incorrect values.
