🔁 Boot-Up Steps (STM32):

  • Power ON or Reset
  • CPU fetches first two words from Flash:
    • 0x00000000 → Set MSP (Main Stack Pointer)
    • 0x00000004 → Load Reset_Handler address into PC
  • Control jumps to Reset_Handler
  • Reset_Handler typically:
    • Copies .data from Flash to RAM
    • Zeros out .bss
    • Calls SystemInit() (clock, PLL, etc.)
    • Jumps to main()
  • If an interrupt happens later:
    • CPU finds the handler's address in the vector table
    • Jumps to it automatically

📌 Detailed Explanation with Examples

🔹 Vector Table (0x00000000)

Located at the start of the memory map, it contains addresses for startup and interrupts.

// First three entries in vector table
0x00000000 → Initial Stack Pointer
0x00000004 → Reset_Handler address
0x00000008 → NMI_Handler()

Flash Memory (.text, .rodata) (0x08000000 – 0x080FFFFF)

🔹 .text Section (Flash)

Stores executable code. This is where your firmware logic lives.

void blinkLED(void) {
    // Code stored in Flash
    GPIOA->ODR ^= (1 << 5);
}

🔹 .rodata Section (Flash)

Stores constant data (read-only).

const char msg[] = "Hello, World!";  // Stored in .rodata

SRAM (RAM): .data, .bss, stack, heap (0x20000000 – 0x2001FFFF : 128KB)

Temporary workspace while the MCU is running

🔹 .data Section (RAM)

Global/static variables that are initialized (copied from Flash to RAM on startup).

int speed = 100;  // Stored in .data section

🔹 .bss Section (RAM)

Global/static variables that are uninitialized. Zeroed at startup.

int counter;  // Stored in .bss section

🔹 Stack (RAM)

Used for local variables, function calls. Grows downward.

void func() {
  int temp = 42;  // Stored on the stack
}

🔹 Heap (RAM)

Dynamic memory (malloc/free). Grows upward.

char *buffer = malloc(100);  // From heap

🔹 Peripheral Registers (0x40000000+)

Control hardware like GPIO, UART, timers using memory-mapped registers.

#define RCC_APB2ENR  (*(volatile unsigned int*)0x40021018)
#define GPIOA_CRL    (*(volatile unsigned int*)0x40010800)

RCC_APB2ENR |= (1 << 2);      // Enable GPIOA
GPIOA_CRL &= ~(0xF << 20);    // Clear config
GPIOA_CRL |= (0x1 << 20);     // Set PA5 as output

🔹 System Control Space (0xE000E000+)

Handles interrupts, system exceptions, and timers (e.g., SysTick).

SysTick_Config(SystemCoreClock / 1000);  // Configure 1 ms SysTick interrupt

Aliased Memory at 0x00000000

  • Purpose : Some MCUs mirror Flash to 0x00000000 so that the Reset vector and boot process always start from there.
  • Aliased To : Real Flash address (e.g., 0x08000000)
  • Why It Exists : ARM Cortex-M always starts from 0x00000000. MCU vendors map actual Flash here using a memory alias.

🛠 Tips for Freshers

  • Use const for data that doesn't change — it saves RAM.
  • Check your memory layout using the .map file or debugger memory view.
  • Heap and stack grow toward each other — monitor usage to prevent overflow.
  • Use volatile for registers and shared memory with interrupts.
  • Understand how the linker script places sections in memory.
