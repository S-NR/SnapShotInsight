Cypress FX3 – Programming Overview

Cypress FX3 is a high-performance USB 3.0 peripheral controller widely used in imaging, data acquisition, and high-speed streaming applications. This page explains the overall programming concept before diving into low-level details.

1️⃣ FX3 Architecture (At a Glance)

  • 32-bit ARM9 CPU running FX3 firmware.
  • High-speed USB 3.0 / USB 2.0 device controller.
  • On-chip SRAM for firmware execution.
  • Interfaces: GPIF-II, I2C, SPI, UART, GPIO.
FX3 executes firmware only from SRAM (Flash is used for storage, not execution).

2️⃣ FX3 Boot Flow

  • On reset, FX3 BootROM starts execution.
  • BootROM looks for firmware in a predefined order:
USB Boot Development / Debug
I2C / SPI Flash Production Mode
UART Recovery / Factory
Firmware is always copied into SRAM before execution.

3️⃣ FX3 Firmware Programming Model

  • Firmware is written in C using FX3 SDK.
  • Uses Cypress-provided RTOS.
  • Application is event-driven (threads, callbacks, interrupts).
  • USB, GPIF, DMA configured using APIs.

4️⃣ Interface Usage in FX3

  • USB – Host communication (PC / FPGA).
  • GPIF-II – High-speed parallel data interface.
  • I2C / SPI – Sensor, EEPROM, Flash access.
  • UART – Debug logs.
FX3 acts as a bridge between USB and external data sources.
