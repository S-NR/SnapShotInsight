MCU Programming: SRAM vs Flash

Microcontrollers support two common ways to load and run firmware during development and production.

1️⃣ On-Chip SRAM Programming (Debug Mode)

  • Code is loaded directly into SRAM using a debugger (JTAG / SWD).
  • Used for functional testing and debugging.
  • Program is lost after reset or power-off.
  • Fast load time → ideal during development.
  • Not used for final delivery.
Example: Running code from IDE using "Run / Debug" button.

2️⃣ Flash Programming (Production Mode)

  • Code is programmed into internal Flash memory.
  • Firmware persists after power-off or reset.
  • Used for client delivery, field testing, and production.
  • Can be programmed via USB / Bootloader / External programmer.
Example: Programming firmware before handing the board to QA or customer.
