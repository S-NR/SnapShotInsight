🧪 STM32 GPIO Practical Example – Button Controls LED

This is a basic STM32 example using HAL (via STM32CubeMX) where:

  • A button is connected to GPIOA Pin 0 (configured as input with pull-up).
  • An LED is connected to GPIOA Pin 5 (configured as output push-pull).
  • When the button is pressed, the LED turns ON. When released, the LED turns OFF.

🛠️ Hardware Configuration

ComponentPinMode
ButtonPA0Input + Pull-up
LEDPA5Output Push-Pull

🔧 GPIO Initialization Code (CubeMX generated)

void MX_GPIO_Init(void)
{
  GPIO_InitTypeDef GPIO_InitStruct = {0};

  __HAL_RCC_GPIOA_CLK_ENABLE();

  // Configure PA0 as input with pull-up
  GPIO_InitStruct.Pin = GPIO_PIN_0;
  GPIO_InitStruct.Mode = GPIO_MODE_INPUT;
  GPIO_InitStruct.Pull = GPIO_PULLUP;
  HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);

  // Configure PA5 as output push-pull
  GPIO_InitStruct.Pin = GPIO_PIN_5;
  GPIO_InitStruct.Mode = GPIO_MODE_OUTPUT_PP;
  GPIO_InitStruct.Pull = GPIO_NOPULL;
  GPIO_InitStruct.Speed = GPIO_SPEED_FREQ_LOW;
  HAL_GPIO_Init(GPIOA, &GPIO_InitStruct);
}

🧠 Main Logic (LED Control)

int main(void)
{
  HAL_Init();
  SystemClock_Config();
  MX_GPIO_Init();

  while (1)
  {
    if (HAL_GPIO_ReadPin(GPIOA, GPIO_PIN_0) == GPIO_PIN_RESET)
    {
      // Button pressed (pull-up = active LOW)
      HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_SET); // LED ON
    }
    else
    {
      HAL_GPIO_WritePin(GPIOA, GPIO_PIN_5, GPIO_PIN_RESET); // LED OFF
    }

    HAL_Delay(10); // Debounce delay
  }
}

📝 Notes

  • HAL_GPIO_ReadPin() reads the status of an input pin.
  • HAL_GPIO_WritePin() sets/reset an output pin.
  • GPIO_PULLUP keeps the input HIGH when button is not pressed.
  • Simple debouncing is done using HAL_Delay(10).

✅ Result: When button on PA0 is pressed, LED on PA5 turns ON.
