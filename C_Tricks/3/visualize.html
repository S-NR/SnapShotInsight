🧠 sizeof: Array vs Pointer

Visual explanation · Same code · Different behavior

The Code

void print_elements_inside_function(int *buffer)
{
    int length = sizeof(buffer) / sizeof(buffer[0]);

    for (int i = 0; i < length; i++)
        printf("%d ", buffer[i]);
}

int main(void)
{
    int data_array[10];

    for (int i = 0; i < 10; i++)
        data_array[i] = i + 1;

    print_elements_inside_function(data_array);

    int length = sizeof(data_array) / sizeof(data_array[0]);
    for (int i = 0; i < length; i++)
        printf("%d ", data_array[i]);
}

✔ The Correct Fix

void print_elements_inside_function(int *buffer, size_t length)
{
    for (size_t i = 0; i < length; i++)
        printf("%d ", buffer[i]);
}

print_elements_inside_function(
    data_array,
    sizeof(data_array) / sizeof(data_array[0])
);

✔ Full array processed safely

Final Takeaway

sizeof(array) works only where the array is declared.
Inside a function, it is already a pointer.
