🧠 C Programming Puzzle

Snapshot Insight · Looks right, breaks silently

The Question

What is the value of len inside the function?

#include <stdio.h>

void send(int *buf)
{
    int len = sizeof(buf) / sizeof(buf[0]);
    printf("Length = %d\n", len);
}

int main(void)
{
    int data[10] = {0};
    send(data);
    return 0;
}

Your Answer:

Explanation

visualize the concept

This code contains a classic sizeof trap in C.

  • In main(), data is a real array: int data[10]
  • When passed to send(), the array decays to a pointer
  • Inside send(), buf is only int * 
sizeof(buf)      → size of pointer (4 or 8 bytes)
sizeof(buf[0])   → size of int (usually 4 bytes)

So the result becomes:

64-bit system → len = 8 / 4 = 2
32-bit system → len = 4 / 4 = 1

🚨 No compiler warning. No crash. Just silent data loss.

✔ Correct Fix

void send(int *buf, size_t len)
{
    // use len safely
}

int data[10];
send(data, 10);

Golden Rule:
sizeof(array) works only in the scope where the array is declared.
