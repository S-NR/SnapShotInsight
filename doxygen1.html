Doxygen → PDF (From Scratch)

Beginner‑friendly steps to turn existing Doxygen comments in your code into a polished PDF on Windows.

1) Install Doxygen

  1. Download and install Doxygen (Windows installer).
  2. Optional: add doxygen.exe to your PATH to run it from any folder.

2) Install LaTeX (for PDF)

  1. Install MiKTeX (recommended). During setup, enable Install missing packages on the fly and Add MiKTeX to PATH.
  2. Open a new terminal and verify: 
    pdflatex --version
If the command is not found, add MiKTeX's miktex\bin\x64 directory to your PATH, then reopen the terminal.

3) Create a Doxyfile

In your project root:

doxygen -g Doxyfile

4) Minimal Doxyfile settings

# Where your sources live (adjust as needed)
INPUT = ./Sources
RECURSIVE = YES

# Outputs
GENERATE_HTML  = YES
GENERATE_LATEX = YES

# Optional (keeps things tidy)
OUTPUT_DIRECTORY = docs

5) Run Doxygen

doxygen Doxyfile
# Expect: docs/html/ and docs/latex/ (or html/ and latex/ if OUTPUT_DIRECTORY not set)

6) Build the PDF

Go to the LaTeX folder and compile:

cd docs/latex
pdflatex refman.tex
makeindex refman.idx
pdflatex refman.tex
pdflatex refman.tex

Output: refman.pdf appears in the same folder.

Tip: You can also run the auto script generated by Doxygen: make.bat (Windows) in the latex folder.

7) Open the PDF

docs/latex/refman.pdf

Troubleshooting

  • "'pdflatex' is not recognized" → MiKTeX not installed or not in PATH. Add C:\\Program Files\\MiKTeX\\miktex\\bin\\x64 (or your user install path) to PATH. Reopen terminal.
  • Missing packages → Allow MiKTeX to install on-demand when prompted, or pre-install via MiKTeX Console.
  • Broken TOC / references → Run pdflatex multiple times.
  • Paths with spaces → Wrap in quotes, e.g. "D:\\Projects\\Head start training\\...".

Optional: RTF → PDF (No LaTeX)

In Doxyfile:

GENERATE_RTF = YES

Run Doxygen, open the .rtf in Word, then Save as → PDF.
