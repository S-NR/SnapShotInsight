📊 Microcontroller Memory Map Comparison

🔧 STM32 (ARM Cortex-M)

+---------------------------+  0xE000E000  
| System Control Space      | (SysTick, NVIC, SCB)
+---------------------------+  0x50000000  
| Peripheral Registers       | (Advanced peripherals)
+---------------------------+  0x40000000  
| Peripheral Registers       | (GPIO, UART, SPI, I2C)
+---------------------------+  0x2001FFFF  
|        SRAM (RAM)          |
|  - .data, .bss             |
|  - Heap (↑), Stack (↓)     |
+---------------------------+  0x20000000  
|        Reserved            |
+---------------------------+  0x080FFFFF  
|        FLASH Memory        |
|  - .text, .rodata          |
|  - Vector Table            |
+---------------------------+  0x08000000  
|       Aliased at           |
+---------------------------+  0x00000000

🔧 ATmega328P (AVR - Arduino Uno)

+---------------------------+  0x08FF  
| SRAM (2KB)                |
| - Stack, .data, .bss      |
+---------------------------+  0x0100  
| Internal SRAM Start       |
+---------------------------+  0x00FF  
| SFR (Special Function Reg)|
+---------------------------+  0x0020  
| I/O Registers             |
+---------------------------+  0x0000  
| FLASH (32KB)              |
| - .text, .rodata, vectors |
+---------------------------+  0x7FFF

🔧 PIC32 (MIPS M4K)

+---------------------------+  0xBFC02FFF  
|  Debug Exec Memory        |
+---------------------------+  0xBFC02000  
| Debug Code                |
+---------------------------+  0xA000FFFF  
| Uncached RAM (kseg1)      |
+---------------------------+  0xA0000000  
|                           |
+---------------------------+  0x9D1FFFFF  
| Flash Program Memory      |
| - .text, .rodata          |
+---------------------------+  0x9D000000  
| kseg0 Code (cached)       |
+---------------------------+  0x8000FFFF  
| Cached RAM (kseg0)        |
| - .data, .bss             |
+---------------------------+  0x80000000

🔧 8051 Microcontroller

+---------------------------+  0xFFFF  
| External Data (XDATA)     | (accessed via MOVX)
+---------------------------+  0x0000  
|                           |
+---------------------------+  0xFF  
| Internal RAM (upper)      | 128 bytes (indirect)
+---------------------------+  0x80  
| SFR (I/O Registers)       |
+---------------------------+  0x7F  
| Bit-addressable RAM       |
+---------------------------+  0x20  
| General-purpose RAM       |
+---------------------------+  0x00  
| Internal RAM (lower)      |
+---------------------------+  0x0000  
| Flash Program Memory      | up to 64 KB (accessed via PC)
+---------------------------+  0xFFFF

🔧 MSP430 (TI Low Power MCU)

+---------------------------+  0xFFFF  
| Interrupt Vectors         |
+---------------------------+  0xFC00  
| Flash Memory              |
| - .text, .const           |
+---------------------------+  0xC000  
| Info Flash (calibration)  |
+---------------------------+  0x1000  
| RAM                       |
| - .bss, .data, Stack      |
+---------------------------+  0x0200  
| Special Function Registers|
+---------------------------+  0x0100  
| Peripherals               |
+---------------------------+  0x0000

🔧 RP2040 (Raspberry Pi Pico – Dual Cortex-M0+)

+---------------------------+  0x20042000  
| SRAM5 (8 KB)              |
+---------------------------+  0x20040000  
| SRAM4 (8 KB)              |
+---------------------------+  0x2003C000  
| SRAM3 (16 KB)             |
+---------------------------+  0x20030000  
| SRAM2 (16 KB)             |
+---------------------------+  0x20020000  
| SRAM1 (16 KB)             |
+---------------------------+  0x20000000  
| SRAM0 (128 KB total)      |
+---------------------------+  0x10000000  
| XIP FLASH (16 MB mapped)  |
| - Firmware starts here    |
+---------------------------+  0x00000000

🗂 Summary Table

MCU Flash Start SRAM Start Peripherals Notes
STM32 0x08000000 0x20000000 0x40000000 Cortex-M layout
ATmega328P 0x0000 0x0100 0x0020–0x00FF Separate EEPROM
PIC32 0x9D000000 0x80000000 0xBF800000 MIPS (kseg0/kseg1)
8051 0x0000 0x00 0x80–0xFF Split RAM, XRAM
MSP430 0xFC00 0x0200 0x0100–0x01FF Info Flash & Vectors
RP2040 0x10000000 0x20000000 Memory-mapped IO XIP Flash via QSPI
